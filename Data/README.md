
## Data Source

This project uses the **CSIRO Electric Vehicle Uptake Projections** dataset, which provides projections of electric vehicle adoption and electricity consumption across Australian postcodes.

**Source:** [CSIRO Data Shop — EV Uptake Projections](https://agdatashop.csiro.au/ev-uptake-projections)

### Download Instructions

1. Visit the CSIRO Data Shop using the link above.
2. Download the available projection datasets for:
   - NSW & ACT (`NSWACT`)
   - Northern Territory (`NT`)
   - Queensland (`QLD`)
   - South Australia (`SA`)
   - Tasmania (`TAS`)
   - Victoria (`VIC`)
   - Western Australia (`WA`)
3. Extract the downloaded files.

### Data Availability

The original CSV files are not included in this GitHub repository due to their size. Users must download them directly from CSIRO.

The Python scripts are designed to process files matching the pattern `FLEET_*.csv`.
